SysAdmin Toolbox provides a foundation for management and maintenance tools for sysadmins in schools.

== Description ==

This plugin initializes a secure and extensible toolbox architecture for sysadmin workflows in school environments.

Key features:

* Secure plugin bootstrap with ABSPATH checks.
* Activation, deactivation, and uninstall lifecycle hooks.
* Internationalization support with text domain sysadmin.
* Admin page under Tools > SysAdmin Toolbox.
* Separated admin/public classes and assets.

== Installation ==

1. Upload the folder to /wp-content/plugins/.
2. Activate "SysAdmin Toolbox" in the WordPress Plugins screen.
3. Go to Tools > SysAdmin Toolbox.
